🇨🇮 Convertisseur GeoJSON HDX

Cet outil télécharge les frontières administratives de la Côte d'Ivoire et les découpe par niveau.

Étape 1 : Télécharger le GeoJSON HDX

Source : OCHA COD-AB Côte d'Ivoire (13 Mo, 3 niveaux admin)

Étape 2 : Télécharger les fichiers découpés

Chaque fichier est simplifié (~70% plus léger) et prêt à héberger sur Supabase Storage.

Étape 3 : Héberger sur Supabase Storage

  1. Dans Supabase, allez dans Storage → New bucket → nom : geojson → Public
  2. Uploadez les 3 fichiers (districts.geojson, regions.geojson, depts.geojson)
  3. Copiez les URLs publiques de chaque fichier
  4. Ajoutez ces URLs comme variables d'env dans Vercel :
VITE_GEOJSON_URLS_DISTRICTS = https://xxx.supabase.co/storage/v1/object/public/geojson/districts.geojson
VITE_GEOJSON_URLS_REGIONS = https://xxx.supabase.co/storage/v1/object/public/geojson/regions.geojson
VITE_GEOJSON_URLS_DEPTS = https://xxx.supabase.co/storage/v1/object/public/geojson/depts.geojson
